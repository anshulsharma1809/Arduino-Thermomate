# Arduino Thermomate 🌡️

## Project Overview

Arduino Thermomate is a temperature-controlled fan system developed as an academic electronics project during my B.Tech in Electronics & Communication Engineering.

The system monitors temperature using a temperature sensor and automatically controls a fan based on the measured temperature.

## Objectives

- Monitor temperature electronically
- Control a fan according to temperature
- Understand sensor interfacing with Arduino
- Understand relay and PWM-based control
- Display temperature readings

## Hardware Used

- Arduino
- DHT11 / LM35 temperature sensor
- 16x2 LCD
- Relay
- DC Fan
- Potentiometer
- Connecting wires
- Power supply
